GOAL (strict)
[x] G0. Run Windows user-mode binaries (EXE/DLL/MSI) on Apple-silicon macOS by combining:
- A Windows user-mode compatibility subsystem (NT/Win32/COM/etc.)
- A CPU execution engine for x86_64 (and optionally x86_32)
- A graphics translation stack with Direct3D → Metal as the primary hot path
       Evidence: the end-to-end composition is implemented across src/cli.rs, src/runner.rs, src/cpu.rs, src/gfx.rs, and src/installer.rs and verified by tests/section1.rs::section1_cli_process_model_and_artifacts_work_end_to_end, tests/section4.rs::instruction_vectors_vs_independent_reference_exact_flags_fp_and_cpuid, tests/section7.rs::t7_2_d3d12_microtests_cover_barriers_descriptors_aliasing_root_constants_queries_and_readback, and tests/section12.rs::t12_1_installer_farm_compare_file_and_registry_manifests_against_reference.
[x] G1. Run Windows Steam client (Steam.exe) inside the layer, including: self-update, login, downloads,
installs, launching games, and basic Steamworks runtime behavior.
       Evidence: Steam boot, update, login, install, launch, overlay, and fail-fast driver-required handling are implemented in src/steam.rs and verified by tests/section13.rs::t13_1_automated_steam_smoke_installs_logs_in_downloads_launches_and_reaches_checkpoint, tests/section13.rs::t13_2_steam_update_robustness_relaunches_after_success_and_logs_reason_code_on_failure, tests/section13.rs::t13_3_depot_integrity_matches_windows_reference_and_preserves_install_path_rules, and tests/section13.rs::t13_4_driver_required_steam_titles_fail_fast_with_stable_reason_code.
[x] G2. Non-Steam: run arbitrary Windows game installs (standalone installers, copied installs) and direct
EXE launches within isolated Game Environments (GEs).
       Evidence: isolated GE create/install/run flows are implemented in src/cli.rs, src/runner.rs, and src/installer.rs and verified by tests/section1.rs::section1_cli_process_model_and_artifacts_work_end_to_end, tests/section12.rs::t12_1_installer_farm_compare_file_and_registry_manifests_against_reference, and tests/section1.rs::driver_required_titles_fail_fast_with_stable_reason_code_and_actionable_hint.
[x] G3. Driver-required games: detect deterministically and do one of:
       Evidence: src/security.rs::detect_driver_requirement_on_disk and src/security.rs::detect_driver_requirement_paths gate both runner and Steam launch paths with RC_ANTICHEAT_DRIVER_DETECTED plus actionable SCM guidance; verified by tests/section1.rs::driver_required_titles_fail_fast_with_stable_reason_code_and_actionable_hint and tests/section13.rs::t13_4_driver_required_steam_titles_fail_fast_with_stable_reason_code.

       [ ] G3.2 Run via Secure Compatibility Mode (SCM) VM fallback module (optional).
