# Guest Environment Snapshots (ges/)

This directory contains tracked Guest Environment snapshots used as test fixtures
for Casa1's Steam and Windows compatibility layers.

## Directory Layout

| Directory | Purpose |
|-----------|---------|
| `replay/` | Minimal GE snapshot for replay-based tests |
| `steam-live-run/` | Steam x64 runtime snapshot (SteamSetup.exe installer output) |
| `steam-live-run-x86/` | Steam x86 runtime snapshot (SteamSetup.exe installer output) |

## Binary Fixtures

### `steam-live-run/`

| File | Origin | Purpose | Update Process |
|------|--------|---------|---------------|
| `SteamSetup.exe` | Official Steam installer from steampowered.com | Steam client installation for x64 runtime tests | Download from https://cdn.cloudflare.steamstatic.com/client/installer/SteamSetup.exe |
| `drive_c/Steam/Steam.exe` | Output of SteamSetup.exe | Steam x64 client binary | Run SteamSetup.exe in the GE |
| `drive_c/Steam/bin/SteamService.exe` | Output of SteamSetup.exe | Steam x64 service binary | Run SteamSetup.exe in the GE |
| `drive_c/Steam/uninstall.exe` | Output of SteamSetup.exe | Steam x64 uninstaller | Run SteamSetup.exe in the GE |
| `drive_c/Steam/public/steambootstrapper_*.txt` | Output of SteamSetup.exe | Steam UI localization files | Run SteamSetup.exe in the GE |
| `ge.json` | Manually curated | GE configuration for Steam x64 | Edit JSON directly |
| `fs/reparse.db.json` | Generated by Casa1 | Filesystem reparse point database | Regenerate by running `macwin ge:init` |

## Runtime Artifacts

The following are **generated at runtime** and excluded from version control via `.gitignore`:

- `*/*/cache/` — D3D, shader, HTTP, PSO caches
- `*/*/logs/` — Guest execution logs
- `*/*/traces/` — Guest execution traces
- `*/*/reports/` — Run reports
- `*/*/diagnostics/` — Diagnostic dumps
- `*/*/registry/*.db` — Runtime registry databases (regenerated from base fixtures)
- `*/*/drive_c/**/*.tmp` — NSIS installer temp files
- `*/*/drive_c/**/.crash` — Crash dumps
- `*/*/drive_c/**/Temp/` — Windows temporary directories
- `*/*/drive_c/**/logs/` — Steam bootstrap logs
- `*/*/drive_c/**/config/config.vdf` — User-specific Steam config
- `*/*/drive_c/**/package/steam_client_win32.installed` — Install markers
- `*/*/drive_c/users/` — Guest user profile data

To regenerate a clean fixture after updating the Steam installer:

```sh
# Remove runtime artifacts (keeping only tracked fixtures)
cd /path/to/casa1
git clean -fdX ges/steam-live-run-x86/

# Re-run the Steam installer in the GE to produce updated binaries
cargo run --bin macwin -- ge:run --ge ./ges/steam-live-run-x86 --exe ./ges/steam-live-run-x86/drive_c/SteamSetup.exe
```
